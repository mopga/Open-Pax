## 2. Сравнение с Open-Pax (рабочее дерево)

| Механика | Open-Pax сейчас | Разрыв |
|---|---|---|
| Свой ключ / подписка | Только `llm.config.json` / env на сервере; UI нет; дефолт MiniMax | **Критично для цели**: нужен экран настроек провайдера |
| Учёт токенов / стоимость (V3) | `tokensUsed` нигде не сохраняется | Нет usage ledger и счётчика в шапке |
| Обновление карты после хода | `handleTimeSkip` (`frontend/src/App.tsx:522`) и `onJumpEvent` (`App.tsx:767`) не обновляют регионы → изменения видны только после загрузки сейва; `currentWorld.regions` — массив, а код ищет по id (`App.tsx:662, 1249`) | **Блокер**: главная визуальная обратная связь игры не работает |
| Дата старта | `game.repository.ts:18` не пишет `current_date` → до первого хода показывается 1951 | Баг |
| Покрытие карты (V5) | Только страны пресета (41 / 112), остальное пустое | Нужно «весь мир принадлежит кому-то» |
| Подписи (V5) | DOM-маркеры, коллизии в Европе | Нужны изогнутые подписи вдоль оси страны |
| Подложка (V5) | Тёмный фон + сетка | Нужен офлайн-рельеф |
| Флаги | flagcdn.com (интернет) | Положить локально |
| Панель действий (V8) | Плавающая «Control panel», фиктивные кнопки Attack/Develop с «стоимостью» 💰20 ⚔️50 | Перестроить под V8; убрать фейковые стоимости; добавить ✨ и 🎤 |
| Стратегический анализ (V9) | `suggestions` (6–9 тем × 2–5 действий) — данные почти те же | В основном UI: аккордеоны с описанием ситуации |
| Хронология (V11) | 1–4 нед / 1–4 мес / custom / auto | Привести к 1н/1м/3м/6м/1г/своё + «следующее крупное событие» |
| События (V13–V14) | Применяются автоматически с паузой 350 мс; карточка = заголовок + текст | Пошаговое раскрытие по кнопке, сущности-чипы, бейдж изменений, подсветка регионов, озвучка |
| Хаб игр (V1) | Только «продолжить» из сейвов; нет списка игр, удаления, скрытия | Нужен GET /games и автосейв |
| Каталог пресетов (V2) | Простой список + zip import/export | Карточки с обложками, страница пресета, «Мои сценарии» |
| Скорость старта (V4) | BalanceAgent: 1 LLM-вызов на страну (41–112 вызовов, минуты) | Статика из пресета, LLM — опционально |
| Ошибки LLM (V10) | Свободный JSON-repair | Явная ошибка + «Повторить», schema-валидация |
| Язык | Русский зашит в промптах (`prompt-builder.ts:138`) | Настройка языка контента/UI |

## 3. План работ

Порядок: сначала то, что делает игру играбельной локально с любым ключом, потом визуальный паритет, потом глубина симуляции.

### Этап 0 — Гигиена репозитория (0.5 дня)
- [ ] Закоммитить или разделить текущие незакоммиченные изменения (29 файлов, «первый проход» PAX_PARITY_PLAN) — сейчас вся работа висит в рабочем дереве.
- [ ] Разобраться с правами: репозиторий и `node_modules` принадлежат пользователю `testl`, из-под `remote77` git ругается на dubious ownership, `tsc` падает с EPERM.
- [ ] Один менеджер пакетов (в `node_modules` pnpm-раскладка, а lock-файлы — npm).
- [ ] `npm start` сам собирает backend, если нет `dist/`.

### Этап 1 — Свой ключ / подписка / API (главное требование) (3–4 дня)
**Backend**
- [ ] Хранилище настроек в SQLite (`settings`, `llm_profiles`): провайдер, base URL, модель, ключ. Ключ хранится локально (опционально шифруется ключом из ОС/мастер-паролем), **никогда не отдаётся во frontend целиком** (маска `sk-…abcd`).
- [ ] `GET/PUT /api/settings/llm`, `POST /api/settings/llm/test` (пинг модели + проверка JSON-режима), `GET /api/settings/llm/models` (список моделей у провайдера, где есть `/models`).
- [ ] Приоритет конфигурации: UI-настройки → `llm.config.json` → env. Горячая перезагрузка `LLMRouter` без рестарта.
- [ ] Пресеты провайдеров (готовые base URL + модели):
  - API-ключи: OpenAI, Anthropic (нативный), Google Gemini (OpenAI-compatible endpoint), OpenRouter, DeepSeek, Mistral, xAI, Groq.
  - «Подписки» с API-эндпоинтом: MiniMax Token Plan (уже есть), Z.ai GLM Coding Plan, Kimi/Moonshot — это OpenAI/Anthropic-совместимые эндпоинты со своим ключом.
  - Локальные: Ollama, LM Studio, llama.cpp server, vLLM (без ключа).
  - Опционально — «CLI-мост»: вызов уже установленного у пользователя CLI (`claude -p`, `codex exec`, `gemini`) как провайдера. Работает от подписки пользователя, но медленнее и без стриминга JSON; перед включением проверить условия использования конкретного сервиса.
- [ ] Роутинг по механикам из UI: «дорогая» модель для `jump`, дешёвая для `suggestions/converter/advisor/consolidation` (конфиг уже это умеет — нужен только UI).
- [ ] Anthropic: добавить стриминг (сейчас только non-stream) и prompt caching статической части промпта (лор, правила, карта) — сильно режет стоимость jump.

**Usage ledger (V3)**
- [ ] Таблица `llm_calls`: game_id, turn, mechanic, provider, model, input/output/cached tokens, latency, retries, ошибка, оценка стоимости.

- [ ] Стриминговые ответы: брать usage из финального чанка (`stream_options.include_usage` / `message_delta`), иначе — оценка по символам.
- [ ] Шапка: «$0.042 за игру · 18.3k ток.» вместо баланса; страница статистики по механикам; лимит бюджета на игру/день с предупреждением.

**Frontend**

## 4. Критерий «как на видео»
1. Свежая установка → «Настройки» → вставил ключ (или выбрал Ollama) → «Проверить» → OK.
2. Пресет Modern Day → выбор страны → карта целиком раскрашена, подписи изогнутые, загрузка < 5 с.
3. «Помощь с идеями» → 6 тем с вариантами → 2 варианта + 1 свой текст в черновик.
4. ▶▶ → «3 мес» → скелетоны → 8–10 событий по кнопке, каждое с чипами и подсветкой изменений карты, карта меняется на глазах.
5. Шапка показывает реальную стоимость хода по токенам.
6. Выход → «Ваши игры» → «Продолжить» → то же состояние.
