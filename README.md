# Open-Pax

**Локальный симулятор альтернативной истории на ИИ**

*Выбери страну, отдай приказы своими словами, промотай время — и смотри, как мир отвечает.*

[![MIT License](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Node.js](https://img.shields.io/badge/Node.js-20+-green.svg)](https://nodejs.org/)

---

## Что это

Open-Pax — open-source аналог [Pax Historia](https://paxhistoria.co), который работает у тебя на компьютере. Ты играешь за государство, пишешь приказы обычным текстом, выбираешь, на сколько промотать время, а языковая модель симулирует мир: реакции на твои действия, решения других стран, войны, договоры и изменения карты.

Модель — твоя: свой API-ключ, подписка или локальный сервер (llama.cpp, Ollama, LM Studio). Сервер слушает только `127.0.0.1`, ключ хранится в локальной базе.

> Проект в активной разработке. Что уже работает и что планируется — ниже и в [`docs/VIDEO_PARITY_PLAN.md`](./docs/VIDEO_PARITY_PLAN.md).

## Возможности

**Игровой ход**
- Приказы пишутся свободным текстом и копятся в черновике. Отправляются все вместе, когда выбран период.
- «Сгенерировать действия» — ИИ предлагает темы и варианты действий под текущую ситуацию.
- Период скачка: 1–4 недели, 1–4 месяца, свой интервал или «до следующего крупного события». Скачок без приказов тоже работает: мир живёт сам.
- Один вызов симуляции на ход. События приходят по одному, и их можно прервать кнопкой «Вмешаться».
- Нереалистичные приказы симуляция отклоняет и объясняет почему.
- Откат хода, сохранения, пять уровней сложности, сжатие длинной истории (консолидация).
- Советник — чат с главным советником твоей страны.

**Карта**
- Мир поделён на ~930 регионов: области, провинции и штаты Natural Earth, у мелких стран — один регион. Государство владеет регионами, и территория меняется по одному региону.
- Весь мир поделён между государствами: страны вне пресета становятся самостоятельными. Мир собирается из данных пресета за секунду, без вызовов ИИ.
- Поверх заливок лежит офлайн-рельеф Natural Earth. Границы государств и обводка своей страны строятся по реальным общим границам.
- Подписи — шрифт PT Serif, капсом и с разрядкой, изогнутые вдоль главной оси страны и размером по её габаритам, в стиле Pax Historia.
- Карта перекрашивается прямо по ходу событий: аннексии, распад, новые государства.

**Модель ИИ и расход**
- Окно «⚙ Модель ИИ». Готовые пресеты:
  - API: DeepSeek, OpenAI, Anthropic, Google Gemini, OpenRouter, Moonshot;
  - подписки: MiniMax Token Plan, Z.ai GLM Coding Plan;
  - локально: llama.cpp, Ollama, LM Studio, а также любой OpenAI-совместимый сервер.
- Основная модель для симуляции и отдельная лёгкая — для подсказок, советника и обработки приказов. Есть кнопка «Проверить» и загрузка списка моделей у провайдера.
- Журнал расхода: токены (включая кэш), задержки, ошибки и оценка стоимости в $. В интерфейсе игры видна сумма за игру с разбивкой по механикам, можно задать предупреждение о бюджете.

**Сценарии (пресеты)**
- «Холодная война (1951)» (СССР, Югославия и Чехословакия собраны из стран карты) и «Современный мир (2024)».
- Играть можно за любое государство мира; пресет лишь подсказывает рекомендуемые.
- Пресет — это пакет: государства, лор, правила симуляции, переопределения промптов. Импорт и экспорт через zip. Формат — ниже.
- Симуляция создаёт, переименовывает и распускает государства.

## Быстрый старт

Нужен Node.js 20+ (проверено на 24).

```bash
git clone https://github.com/mopga/Open-Pax.git
cd Open-Pax
npm install

# по желанию: рельеф карты — скачает Natural Earth SR_LR (~25 МБ) и нарежет тайлы (~85 МБ)
npm run map:relief

npm start
```

Открой **[http://localhost:5173](http://localhost:5173)**, нажми **«⚙ Модель ИИ»** и подключи модель. Дальше — «Новая игра» → сценарий → страна → «Играть».

Без `map:relief` карта работает, просто без рельефа. Для разработки с автоперезапуском: `npm run start:dev`.

## Модель ИИ

### Через интерфейс (рекомендуется)

Выбери пресет провайдера, вставь ключ (для локальных серверов он не нужен), загрузи список моделей, нажми «Проверить» и «Сохранить». Настройки применяются сразу, без перезапуска.

Советы для локальных моделей:
- **llama.cpp:** запускай `llama-server` с `--jinja` и `--ctx-size 32768` или больше — промпт симуляции большой.
- **Ollama:** длина контекста задаётся в настройках (по умолчанию 32768), Open-Pax передаёт её в запросе как `num_ctx`.
- **LM Studio:** длину контекста выставь при загрузке модели.
- Скорость: ход на модели 27B на RTX 5080 (16 ГБ) занимает около минуты-двух.

### Через файл и переменные окружения

Для тонкой настройки каждой механики отдельно (`jump`, `converter`, `advisor`, `suggestions`, `consolidation`) есть `backend-nest/llm.config.json`, пример — `backend-nest/llm.config.example.json`. Без файла читаются `LLM_PROVIDER`, `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL`. Настройки из интерфейса важнее файла и переменных; кнопка «Сбросить» в окне возвращает к ним.

## Формат пресета

Пресет — каталог `backend-nest/data/presets/<id>/`:

```
preset.json   данные сценария (обязателен)
lore.md       мир до первого раунда — его видит ИИ
rules.md      правила симуляции — их видит ИИ
map.geojson   своя карта вместо регионов Natural Earth (необязательно)
flags/        флаги <КОД>.svg|png (необязательно)
```

`preset.json` описывает только то, что отличается от карты Natural Earth. Остальные страны становятся самостоятельными государствами с русским названием и цветом по умолчанию:

```json
{
  "format": 2,
  "id": "cold_war_1951",
  "name": "Cold War (1951)",
  "description": "Мир разделён на два лагеря…",
  "start_date": "1951-01-01",
  "language": "ru",
  "base_prompt": "1951 год. Мир находится в состоянии холодной войны…",
  "polities": {
    "RUS": { "name": "СССР", "color": "#A83A32", "members": ["UKR", "BLR", "KAZ"] },
    "YUG": { "name": "Югославия", "members": ["SRB", "HRV", "BIH", "SVN", "MNE", "MKD", "KOS"] },
    "USA": { "color": "#8FB3D9", "description": "Описание, которое увидит ИИ" }
  },
  "recommended": ["USA", "RUS"],
  "prompts": { "simulation": "шаблон с ${PLAYER_POLITY}, ${GRAND_MAP_DESCRIPTION}…" }
}
```

- **`polities`** — государства с кодом ISO_A3. Поля `name`, `color` и `description` необязательны. `members` перечисляет страны карты, чьи регионы при старте принадлежат государству.
- **`recommended`** — государства, которые экран выбора покажет первыми.
- **`language`** — язык названий на карте, `ru` или `en`.
- **`prompts`** — переопределение промптов ИИ по механикам.

Старый формат с `country_codes`, `countries`, `country_colors` и `polity_members` тоже читается.

## Разработка

```bash
npm run start:dev                 # backend (tsx watch) + frontend (vite)
npm test -w backend-nest          # тесты backend (vitest, LLM замоканы)
npm test -w frontend              # тесты подготовки данных карты
npm run map:glyphs                # пересобрать глифы шрифта подписей
npm run map:regions               # пересобрать регионы (скачает Natural Earth admin-1, ~15 МБ)
```

Сквозной тест через настоящий интерфейс и настоящую модель — `e2e/run.mjs` (Playwright). Он проходит новую игру за СССР, ход, советника, сейв, откат, тайм-скип и загрузку сейва. Попутно проверяет карту и отсутствие удалённого интерфейса, скриншоты кладёт в `docs/e2e/`. Нужны запущенные `npm run start:dev` и подключённая модель (подойдёт локальная, ход на 27B — около полутора минут):

```bash
cd e2e && npm install && npx playwright install chromium
node run.mjs
```

Структура:

```
backend-nest/   Express + TypeScript + SQLite: игра, симуляция, LLM-слой, настройки, журнал расхода
  data/         пресеты, регионы и геоданные Natural Earth, база open-pax.db (создаётся сама)
frontend/       React 18 + Vite + MapLibre GL
  public/glyphs SDF-глифы PT Serif для подписей карты (в репозитории)
  public/tiles  тайлы рельефа (генерируются, в git не попадают)
scripts/        запуск и сборка ресурсов карты
docs/           планы и разбор референса Pax Historia
e2e/            сценарий Playwright
```
